## 技能压力演练

同一场景：已在 Integration、有已接受 Code；辅助探针改变字节，legacy Plan 无机器场景表，出现历史 Requirement 歧义及 review-cycle-limit，用户要求继续。

旧指导中的基线 Agent 仍要求：“先由 Plan Agent 修订机器契约并重审”，并指出无真实业务失败时 route-back 协议循环。

## 保证边界

控制器核对实际身份、文件可读性、原收据绑定、当前对象预算和原子记账；不证明 Agent 的范围、覆盖、适用性判断正确。GPT/处置仍是 CALLER_ATTESTED，原外审执行保证只属于原对象。仓库不能强制宿主调用 flowctl；不提供重建所有旧损坏阶段的通用恢复器，也不编辑 BCS 业务状态或宿主 Goal。
