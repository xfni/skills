# 实验约定与证据

本文件是实验思路与记录指导，不是固定 schema 或控制器。重要事实可以采用现有项目格式，缺少历史审批文件不要求重建开发流程。

## 策略候选

默认推荐小样本预跑 → 冻结样本配对 → 独立样本复验，由讨论决定是否采用，不能把它套在所有后期观察上。

| 策略 | 回答的问题 | 主要限制 |
| --- | --- | --- |
| 固定样本配对 | 同一输入上的候选与基线差异 | 本地差异不是线上业务收益 |
| 分层采样 | 不同业务、难度、边界组的收益和退化 | 各层覆盖/权重应披露，不能掩盖空层 |
| 单变量 | 一个因素的变化 | 基线含遗留改动时不能声称只改一个因素 |
| 组合实验 | 多个变更的叠加与交互 | 无法拆分归因时直接说明 |
| 边界/失败挑战 | 哪些条件会失效或付出代价 | 不自动变成穷举风险或新产品需求 |
| 前后匹配 | 上线前后相同/相似样本的观察差异 | 匹配覆盖、同期变化和选择偏差限制因果 |

## 逐项讨论

依据人类已有讨论和当前项目事实，自适应处理未决项。常见顺序是「要帮助决定什么 → 最小执行方式 → 比较对象和判据 → 样本/可比性 → 数据处理与去向 → 预算和停止条件」；数据去向决定方法可行性时提前讨论。后期观察可以没有候选实现，已明确的项目不重问，不固定问题数量。

每个问题先给一小段解释，再问一个决定。例如：

> 我在 `scripts/replay.py` 的参数解析和调用处看到，同一输入可以指定基线或候选提示词；目前没有运行它，因此尚不能确认服务连通或实际输出。这支持先用已有回放做冻结样本配对，暂不需要新服务；结果可说明本地样本差异，不能直接证明线上收益。我建议先判断候选是否值得进一步投入。你希望本次优先回答这个问题，还是解释现有失败原因？

示例中的路径、能力和选项仅展示提问形状；实际使用必须换成当前项目核对过的证据。事实、推断与待执行验证分别说明。允许人类选候选、自由描述或“按你的建议”；授权缺口不能以推荐值或无回复补齐。无法从代码确定的事实可留为待验证项，并明确验证失败会怎样限制结论或停止动作。

## 执行方式

选能回答所需问题的最小方式，按实际缺口组合，不把它们当成互斥选项或让人先选技术实现。

| 方式 | 使用依据 | 应交付的证据 |
| --- | --- | --- |
| 复用回放 | 已有接口/CLI/驱动能跑所需基线与候选 | 输入版本、实际命令、两侧输出、指标和失败样本 |
| 小型分析脚本 | 缺抽样、匹配、分层、格式转换或统计能力 | 最小脚本、关键计算验证、结果表与可复现命令 |
| 隔离候选实现 | 必须增加算法、适配器或临时服务才能检验假设 | 实验模块/副本、针对新逻辑与驱动的验证、真实对照结果 |

记录采用的方法、必要理由及待验证能力。实验代码为当前问题服务；额外依赖、服务、开关或抽象要有当前实验必要性。使用现有回放或分析产物不能只凭名字确认适用，要核对输入格式、比较路径和指标实际含义。

## 约定先于执行

一次确认应能回答：目的/非目标、假设、所需结论、基线/候选、主要指标/分母/判定依据、实验路径、实际配额、停止/降级条件、数据留存及清理责任。

## 执行范围

确认的执行范围是一次性、可执行的授权边界，所有数据、实验和审阅角色继承它。范围内动作自动连续推进，不因轮次、重试或角色交接重复询问人类；它不绕过宿主的真实沙箱、网络或凭证限制。

至少明确以下内容：

| 项 | 要明确的边界 |
| --- | --- |
| 生产数据 | 只读数据源/操作、字段类别、时间窗、抽样条件、样本上限及允许重试 |
| 本地执行 | 已关联 worktree、允许写入的实验路径、允许启动的本地服务/依赖和禁止的生产写入 |
| 数据处理 | 本地保留的原始内容/映射/凭证，脱敏规则、允许的留存位置与清理责任 |
| 接收者 | 每个 reviewer 或模型端点可收到的数据类别、目的、确切端点/模型和样本/调用上限 |
| 成本 | 查询、运行、模型调用和时间等计量方式、硬上限、停止和降级条件 |

“完整评测集”默认指保留评测所需结构和语义的**完整脱敏集**，不是未经处理的原始数据。原始标识、映射表和凭证始终只留本地。已确认的完整脱敏集可以在明确允许的 iBrain 端点/模型、数量和预算内直接用于回放或盲评，不逐轮再确认。

若确实需要模型读取原始历史正文，首次确认必须另列正文类别/字段、样本上限、确切接收者/端点/模型及目的；私有部署或保密协议不自动构成这项允许。这个例外不携带凭证或映射表，也不自动授权 reviewer 读取原文。后续只有实际超出已确认范围时才暂停受影响动作并请求修订确认。

预估配额依据方案，不先硬定轮数再挤方案。按项目实际成本选择计量：样本数、查询数、总运行次数、时间或模型调用等；说明硬上限、已用量以及最低有效覆盖。采集/探索/复验/审阅与重试成本都应纳入约定的相应预算，不能默认为“免费追加”。不能准确估算的成本说明范围和计量方法，不伪造精确值。

预跑后数据大量无效、重要分层为空或剩余成本不够复验，可以按照已确认规则缩小结论或结束；改变原目标或突破范围才询问人类。配额协商导致方法改变时，复核受影响部分。

## 预授权包与权限预检

`预授权包`是「执行范围」中预计真正会用到的动作清单，不是第二份审批文件。主 Agent 先定向核对代码、配置优先级、回放入口和运行文档，再把生产只读源/数据类别、精确接收者/端点/模型、测试资源命名空间与副作用、本地服务、worktree 允许路径、reviewer 可见证据、样本/调用/重试/成本/时间硬上限、自动停止条件和排除动作写进同一次方案确认。不可发现的细节标记为预检项，不伪造精确值。只有带可核验安全谓词的未解析测试目标才能条件确认；数据外发的接收者/端点/模型不能以“运行时再说”的形式获得空白授权。

人类确认后，在无人值守执行前运行一次非破坏性预检：

- 核对 worktree、允许写入路径、实验 Goal 和所需角色/工具；
- 只核对凭证名与是否存在，不读取、打印或记录凭证值；
- 核对目标的生产只读或非生产身份、命名空间和启动副作用；
- 必要且已授权时，用最小只读查询或非敏感 fixture 验证连通性、端点/模型和返回协议；
- 核对回放输入、基线/候选路径、指标算法、输出受限位置及测试中间件隔离性；
- 记录已核对、未核对和可能在执行期失效的事实。

`预检本身计入已确认配额`；主动探针先从总配额中预留并扣减，若扣减后低于方案的最低有效覆盖，只做静态核对或请求该项差量配额。若最小请求也会超额，只做静态核对并报告未验证。`不通过试探性生产写入验证权限`，也不用删除、部署、Git 推送、任意数据外发或读密钥值来验证。业务预授权`不能替代宿主沙箱、网络、凭证`和项目规则；需要宿主升权时在预检期发起真实申请，被拒绝后不绕过。运行期凭证、沙箱、网络或远程配额失效是操作缺口，不触发整套业务重新授权。

预检把已知缺口尽量集中在当前人类在场时暴露，但通过不代表后续配额、凭证或远程服务不会变化。执行中真正超出数据源/类别、接收者/模型、资源命名空间、副作用或硬上限时，只请求变化条款的差量授权，其他已确认范围继续有效。

## 多轮试验

- 固定本轮实际基线与候选；包含未提交 diff、必要的未跟踪文件和影响结果的缓存/生成物状态，保留可重建快照/补丁或安全本地提交。HEAD 一致不说明代码一致。
- 记录每次运行的代码/数据版本、参数、命令、环境、退出结果、输入计数/有效分母、指标、失败/排除、时间成本和输出位置。后验改指标/阈值/样本过滤要显式标记，不改写原结论。
- 反复用于调参的探索数据不能充当独立复验。复验集曝光后候选改变，明确失去独立性；若尚有配额且约定允许，可用新独立样本验证，否则限制结论。
- 所有轮次包括负面、未完成和中止均留痕。非确定性条件有必要时使用约定重复和种子，不默许不断运行直到成功。
- 实验驱动可以测试候选算法语义，但仅在实验路径/副本实现；不悄改生产源或默认开关，不为实验建设配置平台。先验证驱动和指标计算的正确性，运行用实际返回/日志等证据，不虚构结果。

## 后期验证

记录前后时间窗、采集条件、匹配字段/规则、覆盖率、未匹配样本及已知同期模型/配置/流量/基础设施变化。描述性前后比较与冻结样本本地配对是不同证据，分别呈现。不能仅看匹配子集就外推所有流量或声称因果。

例如：100/100 条前后样本只有 40 对匹配，这 40 对成功率 70% → 85%，只能先报告“匹配子集观察到 +15 个百分点”；另外 60 条难度未知且同期换了模型，不说明上线导致整体 +15 个百分点。不得把“百分点”写成相对百分比。

## 最少记录

| 记录 | 应能核对的内容 |
| --- | --- |
| 实验约定 | issue/EXP、目标与非目标、方法及理由、关键代码/文档依据、事实/推断/待验证项、已确认范围、配额/停止条件、讨论重要修正 |
| 逐轮记录 | 起始/当前状态、数据版本与位置、改动/参数、实际运行和输出、结果/失败、成本及下一动作 |
| 最终报告与索引 | 改动、效果/代价、全部尝试、证据定位、可信度/限制、建议、reviewer 意见与处置、清理/留存及本地提交 |

不要求重复写三份长文，可以沿用项目文档。真实执行证据与模型总结分开定位，文档、日志和证据索引自身也要检查敏感信息。raw、映射及凭证默认不入 Git；脱敏数据若要入 Git 需满足约定和项目要求，不因“已脱敏”默认提交。

## 结论与停止

按实际证据与预先约定的判定依据说明：支持、否定或尚不能判断哪一项假设，结论适用于哪些样本/环境。科学结论不是阶段“通过”；一次复验失败不自动建立未约定的产品 no-go 规则。

独立审阅应核对关键数据、指标和失败/排除，说明实际可见材料及能证明的边界。没有完成独立核验的结果注明未审阅，不以作者自证替代。重要缺陷无法在配额内解决时，报告不足/限制或真正阻塞，不无限修复，不隐藏已知矛盾。

停止条件包括证据达到所需水平、假设被足够否定、继续试验无有价值增量、成本到上限或安全范围不能支持所需动作。按约定自主停止后，先报告已有结果；不要每个负面结论都索取接受确认。
