# 角色、模型与线程

主 Agent 沿用当前会话模型，推荐 Sol/high 或 Astra/medium，不声称能自动切换主会话。

| 角色 | 默认模型/强度 | 配置 |
| --- | --- | --- |
| exp_data | gpt-5.6-luna/max | 随 exp-data 的 agents/exp-data.toml |
| exp_worker | gpt-5.6-luna/max | 本技能 agents/exp-worker.toml |
| exp_reviewer | gpt-6-astra/medium | 本技能 agents/exp-reviewer.toml |

首次派发核对宿主真实支持的角色、模型和工具。创建时显式指定模型与强度，用隔离上下文提供任务包；不能把含原始数据的整段会话继承给 reviewer。subagent 不再委派。

## 模型替代

人类当次指定优先，真实不可用可替代并记录原因：Sol/high ↔ Astra/medium，Luna/max 可由其一替代。配置文件固定的模型可能覆盖 spawn 的值；使用不同模型时，选宿主通用角色并完整传入相同职责/相关技能和边界，显式设置模型/强度，不加载相冲突的固定模型角色。不擅自修改全局角色文件。

当前宿主未加载自定义角色时也可按此方式使用通用角色，记录实际使用情况；不能编造已加载。所有替代仍需满足相同生产权限与数据目的地限制。无可用独立审阅者时注明未审阅/所需能力，不能把主 Agent 自审称为独立审阅。

## 任务包与所有权

任务包短而完整：issue/EXP、worktree 绝对路径、当前约定及确认范围、当前任务与完成依据、允许读写路径/禁止路径、代码与数据版本、允许的实际证据定位、已用及剩余配额、需要返回的结果。摘要是导航，不替代允许范围内的原始证据。数据与实验角色不问人类、不授权采集、不自行改变假设和产品取舍。

数据 Agent 可以读取确认的原始数据路径，拥有采集/脱敏代码和数据文件；实验 Agent 只读自己的允许输入，拥有候选/回放/分析代码；主 Agent 整理约定和报告；reviewer 只读允许的代码、脱敏数据与证据，返回 stdout/API，不直接改文件。文件分工按实际任务调整，明确“不独占工作区，保留他人修改”；不能两个角色同时写同一文件。

读取原始路径指本地程序处理，不是把原文作为工具结果送入模型会话。数据和实验角色只回传检查过的统计/脱敏片段；完整评测集默认是完整脱敏集，在确认的接收者/端点/模型、数量和预算内可直接用于评测。若需要模型直接消费原始历史正文，先核对首次约定是否明确了正文类别/字段、接收者、端点/模型、目的和上限；缺任一项才报告处理范围变更。映射和凭证不属于该例外。

reviewer 的只读 sandbox 只能约束写入，不能证明无法读取共享文件。主 Agent 提供经过检查的明确允许目录/文件，排除原始数据/映射表/凭证/含敏感内容的输出；角色不得扩大读取范围。若宿主不能满足实际数据访问/目的地要求，改用允许的工作区/工具或说明真缺口，不宣称强隔离已实现。

## 线程、等待与恢复

数据和实验角色按需首次唤起，每个会话各自复用其线程，顺序派发小任务，不强制开启四个并发线程。审阅角色可复用讨论线程，但结果阶段重新给完整证据任务；要求检查反例和失效假设，不维护自己早先的建议。

优先 followup_task 复用已完成的线程，send_message 仅作非中断沟通；发送消息不代表杀进程或更换 Agent。记录返回的真实线程标识，名称不是文件路径。

主 Agent 有本地工作时先做，不忙轮询；真正等待时可订阅 300 秒事件等待，两次超时后发一次非中断进度询问。宿主限制单次等待时长时分段，仍按累计等待计时。完成通知应及时处理，不等凑足超时；一次超时不证明卡死，不重建线程。持续给人类简短状态，不让长等待掩盖下一步。

语义/设计歧义交主 Agent 和 reviewer 定向分析，不因升级模型立刻换 worker。确需替代线程时先核对旧句柄、进程、已写文件和真实任务状态，阻止重叠执行后再交接；无法证明旧任务停止就不启动冲突写任务。跨会话恢复不假设旧句柄仍可用，也不把旧输出直接当新执行证据。恢复前由主 Agent 核对实验记录的 Goal 标识与宿主当前活动 Goal；不匹配时不自动派发或重采。未完成结果保留为未完成，剩余配额不能清零。
