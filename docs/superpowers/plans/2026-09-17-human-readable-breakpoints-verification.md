# Flow 人工断点表述验证

日期：2026-09-17。范围：9 个 Flow skill 与共享契约的人工问询、确认、阻塞及恢复消息；不更改控制器实现、状态枚举、审批条件或宿主权限。本轮未提交、部署或修改业务状态。开始前已有控制器合作模式改动保留。

## 断点检查

| 断点 | 调整 |
| --- | --- |
| 缺 issue、工作目录冲突/会话恢复 | 说明为何需要议题编号；给实际目录与已验证可复制命令，不让用户改状态文件 |
| 未找到文档 | 中文选项及各项影响；Agent 组织内部路径映射，不让用户构造 JSON |
| 初始测试许可/生产回放 | 中文说明本地真实请求、测试资源与清理范围，两种选择分别执行/遗漏什么 |
| 脑暴记录、最终需求确认 | 区分讨论记录准确性与最终开发授权；显示产品摘要，不把摘要绑定作为用户任务 |
| Direct 意图/路线/规格/计划确认 | 展示结果、范围、顺序、风险或执行影响，链接完整文档；不新增 flow-run 交接审批 |
| 角色不可用、评审限次/格式错误 | 先 Agent 诊断；确实需介入时说明维护者动作，不暗示修改计数或口头确认可解除 |
| 独立集成测试确认 | 在对话展示完整可执行测试点、预期结果、读写与清理；不只给文档链接或用例编号 |
| 测试依赖/宿主拒绝/真实测试失败 | 先发现项目事实，仅问剩余资源或说明位置；区分未执行、行为失败和权限拒绝 |
| Goal 冲突、有条件完成 | 问真实任务取舍；说明缺少哪种验证，不制造“接受缺陷”确认门 |

共享格式：当前活动与状态 → 实际问题及影响 → 已核验进展/未执行操作 → 最小所需输入或动作 → 回复后继续位置。可以合并成短段落，不要求每次输出五个标题。真实选择提供选项与影响；错误码、digest/revision、角色与信号细节留在可选维护者诊断。机器 null 不改，用户消息省略未定结果。

## 行为演练

只读基线覆盖缺 issue、外审报告故障、Mongo 隔离范围未知、无前序文档的独立测试。基线并非全面失效：已区分工具问题和业务失败，也未将未知报告提升为通过；主要表述缺陷为直接显示“阶段：Flow 准入；状态：等待中；结果：null”，及将 UNCLASSIFIED_RETRY_EXHAUSTED、runner 边界标记混进普通用户主消息。

更新后的独立演练不输出结果 null，明确实际待办与恢复步骤；未知报告仍需新的有效外审报告。限定重跑将报告封装/解析细节移入维护者诊断，主消息解释为“审查报告格式异常，暂时无法确认审查结果”，并请求联系维护者修复。缺 Mongo 资源时仅问测试库/隔离范围或说明位置，不重复问主机、不收密码。

另一次独立应用检查阅读 9 个技能及共享契约，模拟需求/路线确认、编码角色缺失、外审缺口和不同任务 Goal。发现并修正脑暴规范数据 Show 与用户摘要之间的冲突，以及可见 Decision Brief 强制携带 revision/digest 的残留。限定复查确认这两处已关闭；缺具体上传上限时先问上限，不提前索取完整开发授权。

这些演练是有限次提示词应用检查，不是实际业务执行、多轮统计实验或所有断点都必然正确的证明。
